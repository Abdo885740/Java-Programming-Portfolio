## Tutorial Summary (Week 1 – 10)

### Week 1: Introduction to Java & Setup
- Installed JDK and set up development environment (IntelliJ IDEA / Eclipse)
- Learned Java program structure, `main()` method
- Explored primitive data types (`int`, `double`, `char`, `boolean`, `String`)
- Practiced basic output with `System.out.println()`

### Week 2: Strings, Input, and Conditionals
- String manipulation methods (`length()`, `substring()`, `toUpperCase()`)
- User input using `Scanner` class
- Conditional statements: `if`, `else if`, `else`, `switch`
- Logical operators and comparison operators

### Week 3–4: Control Structures – Loops
- `while` and `do-while` loops
- `for` loops and nested loops
- `break` and `continue` statements
- Pattern printing and loop-based problem solving

### Week 5: Methods and Scope
- Defining and calling methods
- Parameters and return values
- Method overloading
- Variable scope and local variables

### Week 6: Classes and Objects
- Object-Oriented Programming introduction
- Defining classes with fields and methods
- Creating objects using constructors
- `this` keyword and encapsulation

### Week 7: Inheritance and Polymorphism
- Inheritance: `extends` keyword, superclass and subclass
- Method overriding and `super` keyword
- Polymorphism and dynamic method dispatch
- Encapsulation and access modifiers

### Week 8–9: Arrays and ArrayLists
- Single and multi-dimensional arrays
- Array manipulation and traversal
- `ArrayList` class and its methods
- Collections framework introduction

### Week 10: Exception Handling and File I/O
- `try-catch-finally` blocks
- Checked vs unchecked exceptions
- Reading from and writing to files using `FileReader`/`FileWriter`
- Exception propagation and custom exceptions

## How to Run the Projects

### Prerequisites
- Java Development Kit (JDK) installed
- An IDE or text editor
- Git (optional, for cloning)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/[PUT_YOUR_GITHUB_USERNAME]/[PUT_YOUR_REPOSITORY_NAME].git
```

2. Navigate to the desired week's folder:
   ```bash
   cd [PUT_YOUR_REPOSITORY_NAME]/week1
   ```
3. Compile the Java file:
   ```bash
   javac [filename].java
   ```
4. Run the compiled class:
   ```bash
   java [filename]
   ```
